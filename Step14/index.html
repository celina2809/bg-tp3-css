Programmation Web

Huit chapitres pour comprendre comment fonctionne un site web : de la première balise HTML jusqu'aux applications qui parlent à un serveur.

Commencer le cours
8 chapitres

01

Introduction au Web

Quand tu tapes une adresse dans ton navigateur, une conversation commence entre ton ordinateur (le client) et une machine distante (le serveur). Ce chapitre explique comment le Web est né et comment cet échange se déroule.

  • Le modèle client / serveur
  • Sites statiques et sites dynamiques
  • Les trois outils de base : HTML, CSS, JavaScript
02

HTML : la structure

HTML décrit le contenu d'une page : titres, paragraphes, images, liens, listes, tableaux. C'est le squelette sur lequel on ajoute ensuite le style et le comportement. 

<h1>Mon premier titre</h1>
<p>Bonjour le monde !</p>
03

CSS : le style

CSS s'occupe de l'apparence : couleurs, polices, marges, positions. On y découvre aussi Flexbox et Grid pour organiser une page, et le design adaptatif pour qu'elle reste lisible sur téléphone. 

h1 {
  color: tomato;
  text-align: center;
}
04

JavaScript : l'interactivité

Avec JavaScript, la page réagit : un clic sur un bouton, un calcul, un élément qui change de couleur. On apprend les variables, les fonctions, les tableaux, les objets, puis la manipulation du DOM et les événements. 

function direBonjour() {
  console.log("Bonjour !");
}
05

HTTP et formulaires

HTTP est le langage que parlent le navigateur et le serveur : une requête part, une réponse revient. Les formulaires permettent d'envoyer des données saisies par l'utilisateur, avec les méthodes GET et POST.

  • Requêtes et réponses HTTP
  • Les codes de statut (200, 404, 500...)
  • Envoyer un formulaire avec GET ou POST
06

Sites dynamiques

Un site dynamique fabrique ses pages à la demande. Avec Python et le framework Flask, on crée des routes, on reçoit les requêtes du navigateur et on renvoie une page différente selon l'utilisateur. 

@app.route("/")
def accueil():
    return "Bienvenue !"
07

Bases de données

Pour garder les informations (comptes, articles, notes), le serveur s'appuie sur une base de données. On apprend à créer des tables MySQL et à les interroger depuis l'application. 

SELECT nom, prenom
FROM etudiants;
08

SPA et services web

Une application à page unique (SPA) change son contenu sans recharger la page. Grâce à AJAX, JavaScript échange des données au format JSON avec le serveur et met l'affichage à jour en direct.

  • AJAX et la fonction fetch
  • Le format JSON
  • Créer et consommer un service web
